# Servo

Удобный менеджер служб Windows: показывает все службы, их состояние и понятное
описание, позволяет отключать, включать, запускать и останавливать их в один клик.

Сделано на **Tauri 2 (Rust) + React + TypeScript + Tailwind CSS**.

## Возможности

- Список всех служб Windows с цветной точкой состояния:
  - 🟢 работает;
  - 🔴 отключена;
  - 🟡 остановлена, но включена;
  - 🟣 запускается / останавливается.
- Человеческое описание под каждой службой. Если Windows не даёт описание
  (бывает у новых и сторонних служб) — показывается понятный текст с типом запуска.
- Совет по каждой службе: «Можно отключать», «С осторожностью», «Критическая».
- Кнопка **Отключить** сразу меняет тип запуска на «Отключена» и **останавливает
  процесс**, если служба работает.
- Кнопка **Включить** возвращает запуск вручную; рядом можно выбрать тип запуска:
  автоматически / автоматически (отложенно) / вручную / отключена.
- **Системные службы** помечены щитом и отключаются только после подтверждения
  с галочкой «Я понимаю риски».
- **Критические службы** (RPC, питание, сеть, Defender, звук и т. п.) защищены —
  кнопка отключения заблокирована, чтобы случайно не сломать Windows.
- Поиск по названию, имени службы, описанию и совету (`Ctrl+K`).
- Кнопка **Спросить у ИИ** в карточке службы: кратко объясняет, что делает служба,
  что будет при отключении и какую нагрузку она создаёт. Запрос уходит только
  после нажатия кнопки.
- Кнопка **Искать в интернете** открывает Google с готовым вопросом о службе,
  чтобы получить ответ во встроенном AI-обзоре.
- Фильтры: все / работают / остановлены / отключены / системные / сторонние /
  можно отключать. Сортировка по названию, статусу или риску.
- Тёмно-серая «крапчатая» текстура, аккуратные карточки, анимации.
- Работает без прав администратора в режиме просмотра; для изменений —
  кнопка перезапуска с UAC.

## Требования

- Windows 10/11 x64.
- WebView2 Runtime (в Windows 11 уже установлен; в Windows 10 обычно тоже).
- Node.js 20+ — только для сборки.

Rust-тулчейн и MinGW уже лежат **внутри папки проекта** (`rust-cargo`, `rustup`,
`tools\mingw64`), глобально ничего ставить не нужно.

## Сборка

```bat
build.bat
```

Результат: `src-tauri\target\release\servo.exe`.

Это готовый портативный exe: установка не требуется. Файл можно скопировать на
другой компьютер с Windows 10/11 (там должен быть WebView2 Runtime — в Windows 11
он уже есть).

Запуск в режиме разработки:

```bat
dev.bat
```

### Про путь к папке

GNU-линкер (MinGW), которым собирается Rust, не умеет работать с путями, где есть
пробел и кириллица. Поэтому папка проекта физически лежит в `F:\servo`, а
`F:\Новая папка` — это junction (псевдоним) на неё: открывать и запускать всё можно
по привычному пути, но сборщик получает «чистый» ASCII-путь.

Все три `.bat`-файла сами определяют физический путь папки, так что сборка
работает и в этом случае, и если папку когда-нибудь перенесут в путь без
кириллицы.

## Как пользоваться

1. Запустите `servo.exe`.
2. Для просмотра права администратора не нужны. Чтобы что-то менять — нажмите
   «Обычный режим» в правом верхнем углу и подтвердите UAC.
3. Найдите службу через поиск или фильтр.
4. Нажмите **Отключить** — служба будет отключена и остановлена.
5. Вернуть всё обратно: **Включить**, затем **Запустить**.

## Безопасность

- Критические службы Windows отключить нельзя — кнопка заблокирована.
- Системные службы требуют явного подтверждения.
- Все действия обратимы: тип запуска можно вернуть в любой момент.
- Servo не удаляет службы и не трогает реестр напрямую — только штатные
  команды диспетчера служб Windows.

## Структура

```
src/                 React-интерфейс
  components/        карточка службы, диалог, тосты, сайдбар
src-tauri/src/
  services.rs        WinAPI: перечисление и управление службами
  kb.rs              база знаний: описания и оценка риска
  admin.rs           проверка прав и перезапуск с UAC
  lib.rs             команды Tauri
rust-cargo/          локальный cargo и кэш крейтов
rustup/              локальный тулчейн Rust (GNU)
tools/mingw64/       локальный MinGW (gcc, ld, windres)
tools/windres/       windres + dlltool + as для сборки ресурсов
```
